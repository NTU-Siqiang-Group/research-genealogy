# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older
research snapshots are retained for reproducibility but are not maintained as
supported software releases.

## Reporting a vulnerability

Please use GitHub's **Security → Report a vulnerability** flow for this
repository. Do not disclose a vulnerability in a public issue.

Include the affected version or commit, impact, minimal reproduction steps, and
any suggested mitigation. Remove API keys, retrieved PDFs, private result
bundles, and other sensitive research data before submitting the report.

The maintainers will acknowledge the report, assess its scope, and coordinate a
fix and disclosure when appropriate.
